# Security policy

agent-toolkit runs locally (CLIs) or entirely in your browser (teamshift.io/tools). Secrets and payloads you paste are never sent to a server by the core libraries.

If you find a vulnerability (for example, a signature check that accepts a forged webhook), please report it privately through GitHub: **Security tab → Report a vulnerability**. Please don't open a public issue. We aim to respond within 3 business days.
